# 示波器波形自定义标定画图工具（离线单文件分享版）

**纯本地离线工具，不联网、不安装、不上传任何测试截图。**
直接把 [示波器标定画图工具.html](./示波器标定画图工具.html) 发给同事（微信 / 钉钉 / 飞书 / 邮件），**双击用 Edge / Chrome / 360 极速浏览器打开即可直接使用**。

## 三步快速上手

1. **导入图片**：按 `Ctrl + V` 直接粘贴截图，或点「📂 导入图片」/ 一次拖入多张示波器图片（底部自动形成队列）。
2. **锁图自由标定**：
   - 导入后顶部「🔒 底图锁定」默认开启，左键和滚轮不会误触移动或缩放底图。
   - 选顶部绘图工具（`横箭头` / `竖箭头` / `引线` / `分段链` / `文字` / `参考线` / `矩形框`）直接拖画，或点左侧一键添加。
   - **调长度**：鼠标移到箭头两端，大圆点高亮后直接一把拖动（右上角自动弹出 4× 放大镜）。
   - **整体移动**：拖线身或文字即可整体平移（自动磁吸对齐其他标注）。
   - **自由移动与缩放字体框**：选中箭头、自由文字或分段链后：
     - 拖右上方 **紫色「字」手柄**：2D 自由移动文字位置（靠近居中自动吸附，箭头断口/淡出自动跟随，拉离箭头后线身自动闭合）；
     - 拖右下角 **青色方点**：斜向直接缩放字号与字体框大小（8–96px 实时预览，分段链支持每段单独缩放）；
     - 拖右边/底边 **青色短条**：自由拉伸字体框宽度与高度（拉窄自动多行换行，配合黑底胶囊/带框底盒效果更佳），也可在右侧面板直接输入宽高或一键恢复自动适配。
   - **一排 / 一列一键对齐**：点击顶部 **`⬚ 框选对齐 (M)`**（或左侧「框选范围」按钮，也可在空白处直接按住左键拖框），框住大致一排或一列即可（绝不误抓箭头；也支持按住 `Shift` 点击多选 / `Ctrl + A` 全选），画布上方会自动弹出快捷对齐条：
     - **一排对齐**：`═ 一排齐平`（中心水平对齐）、`⫟ 顶对齐`、`⫠ 底对齐`、`⫴ 水平等距`、`字排齐`（仅对齐文字高度）；
     - **一列对齐**：`║ 一列齐平`（中心垂直对齐）、`⫤ 左对齐`、`⫣ 右对齐`、`☰ 垂直等距`、`字列齐`（仅对齐文字水平位置）；
     - 多选后也可直接拖动整体平移、方向键整体微调或 `Ctrl + D` 批量复制。
   - **原地改字**：双击画布上任意标注直接弹出输入框修改。
   - **新手引导**：首次使用可点击页面内的 **「🧭 30秒新手引导」** 或右上角 **「❓ 使用指南」**（快捷键 `F1`）。
3. **无损出图**：点 **「📄 复制成品」**（`Ctrl + C`）直接粘贴到 Excel / WPS / Word（若个别浏览器限制本地文件写剪贴板，会自动弹出高清预览窗，右键「复制图像」即可）；或点 **「⬇ 导出 PNG」** / **「⬇ 批量导出全部」**。

## 常用快捷键

- `V` 选择 · `H` 横箭头 · `Y` 竖箭头 · `A` 引线 · `S` 分段链 · `T` 文字 · `G` 竖参考线 · `L` 横参考线 · `R` 矩形框
- `Ctrl + V` 粘贴截图 · `Ctrl + C` 复制成品图 · `Ctrl + D` 复制选中标注 · `Del` 删除
- `Ctrl + Z` / `Ctrl + Y` 撤销 / 重做 · `←↑↓→` 1px 微调（按住 `Shift` 为 5px）
- `F1` 打开内置使用指南 · `P` 隐藏/显示控制点 · `0` 自适应窗口 · `Ctrl + 滚轮` 缩放 · `空格 + 拖动` 平移
