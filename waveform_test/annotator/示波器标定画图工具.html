📖 示波器波形自定义标定画图工具 · 使用指南

第一步：导入图片（自动锁定防误触）

  • 直接按 Ctrl + V 粘贴微信/示波器截图，或点击「📂 导入图片」/ 把多张图片一起拖进窗口。
  • 图片导入后顶部 「🔒 底图锁定」 默认开启：左键点击空白或滚动滑轮都不会误拖/误缩放底图，专心画箭头。
  • 如需放大看极细脉冲，点顶部 ＋ / － 或按住 Ctrl + 滚轮；按住 空格 + 拖动 可平移画布。

第二步：自由画箭头与自定义标注（8 种工具）

  • 点顶部工具栏（横箭头 / 竖箭头 / 引线 / 分段链 / 文字 / 竖横参考线 / 矩形框）在图上拖动绘制，或直接点左侧「快速添加」。
  • 拉长短：鼠标移到任意箭头左/右两端，大圆点高亮后直接一把拖动（无需先选中），右上角自动弹出 4× 像素放大镜 精准对齐光标线。
  • 整体移动：按住箭头线身或文字任意处即可平稳拖动，自动磁吸对齐其他标注（显示粉色对齐线）。
  • 自由移动与缩放文字框：选中箭头、文字或分段链后，拖动文字右上方的 紫色「字」手柄 可自由移动位置（箭头断口自动跟随）；拖动右下角 青色方点 可直接斜向缩放字号与文字框大小；拖动右边/底边 青色短条 可自由拉宽/拉高字体框（拉窄自动换行）。
  • 一排 / 一列一键对齐：在画布空白处直接按住鼠标左键拖框，框住一排或一列的大概范围（或按住 Shift 点击多选），顶部会自动弹出对齐条，一键点 「═ 一排齐平」 / 「║ 一列齐平」 / 左对齐 / 右对齐 / 等距分布 / 仅对齐文字！
  • 改文字：双击画布上的任意标注即可原地弹出输入框直接改字。
  • 样式定制：右侧面板支持单独修改颜色、居中淡出/实线/虚线、箭头造型、字号与黑边防遮挡，并可一键「样式套用至同类/全部」。

第三步：无损出图（所有控制点与辅助框都不会导出）

  • 点 「📄 复制成品」（或按 Ctrl + C）可直接粘贴到 Excel / WPS / Word 测试报告。
  • 点 「⬇ 导出 PNG」 或底部 「导出 JPG」/「⬇ 批量导出全部」 保存原始分辨率无损图片。
  • 点 「💾 存工程」 可把标注保存为 JSON，下次载入同一张底图继续修改。

⛓ 分段箭头链（按时间数据自动等比例切分）

添加「分段链」后，在右侧「分段箭头链数据」里输入数字序列并按回车，即可按比例自动切分各段与间歇（点击下方示例可复制）：

场景写法示例效果说明
连续多段4, 2, 2 自动生成 t1=4.0s、t2=2.0s、t3=2.0s
分段 + 间歇20, (2), 20, (2), 10, (1), 10, (1) 括号自动识别为间歇纯文字，直接上下拖间歇文字可调高度
自定义前缀/单位脉宽=5ms, (1ms), 脉宽2=10ms 自动识别 ms 单位与自定义名称

提示：选中分段链后，线上的粉色菱形手柄可直接左右微调内部分界点；点「恢复比例」可重新严格对齐数据比例。

📏 可选 X / Y 比例尺标定（拖动箭头自动算时间/电压）

  • 在左侧输入已知参考值（如两光标间 22.0 s），点 「在图上点选两点标定 X」（或点 「✨ 找AX/BX」 自动识别黄色光标线）。
  • 标定后选中任意箭头即可看到精确换算值，点 「⚡ 填入换算值」 或勾选 「拖动长度自动更新数值」，拉长箭头数字就会实时跟着变！
