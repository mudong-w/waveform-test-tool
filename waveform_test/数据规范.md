# 波形采集、标定与报告数据规范

## 输入与复核

1. 先冻结当前长记录，保存同一帧的原生截图、原始 CSV 和采集参数。CSV 使用 UTF-8，time_s 为秒，CH1_V 为伏特，时间戳等间隔递增。保存原始精度、采样率、倍率、时基、垂直量程与触发状态。仪器操作结束后恢复采集状态。
2. 屏幕需覆盖一轮完整输出和右侧下一轮复现。以起始间隔的起点为 0.0 s，比较下一次相同边缘、段序、时长和形状。没有间隔时用可复现的相位作基准；自动识别器目前适用于有可辨空闲间隔的重复脉冲列。无间隔、连续跨段或相序交替的信号应另作相位复核。
3. 长记录判定周期和边界。窄脉冲、组内频率、短平台及切换用高采样率局部记录复核。将补采段与长记录对齐，局部测量进入数据目录。核对削顶、传输完整性和频率分辨率。

## 分段和幅频口径

- 各段按出现顺序命名 t1、t2 等，间隔单列。幅度由渐变转平台、扫频转定频或包络转向都可构成段界。连续输出在段界衔接；确认停顿时才画零线。
- 幅度用同一口径的最大值减最小值求 Vpp。需要时分别写正负峰值、单脉冲典型 Vpp 和整轮 Vpp。双相交替记录正负相序，有符号电压用 V。
- 逐脉冲间距、组内脉冲频率、组重复频率、组间停顿和完整波形重复频率分别统计。稀疏脉冲记录实数个数；交替双相按相同相序重现判定完整周期。
- 平台、连续扫频、重复包络和短时阶跃分别按实测形状绘制。保留短平台、重复次数、真实跳变和组间停顿。逐窗峰峰值及采样抖动保存为实测数据；有复核依据的采用曲线供交付使用。

## 采用值与交付

- 原始统计和报告采用值分别保存。依据重复测量选择标称值，各段时长及间隔之和须等于整轮 T。调整任一时长后重算后续起止点。时间显示一位小数，必要时保留半秒，毫秒级参数用 ms；频率和电压用整数并带单位。证据不足写“未确认”。
- 原生截图只标一轮。各段独立箭头尽量排在同一行，T 在下方单列，右侧复现保持可见。箭头指向真实边缘，标签显示采用时长。幅度和频率放在趋势图及说明中。零点复核、测量误差、时间戳和逐点数字收入数据。
- 正式趋势图只含幅度和频率两栏，范围从 0.0 s 到 T。说明按输出顺序列持续时间、频率及电压。各图、表和文字共用同一套采用值。有扫频曲率时用多个实测控制点，避免用直线替代曲率。
- 结果目录顶层放周期标记图、幅频趋势图、说明和带图 Excel；原生底图、原始采样、采集参数、标注工程、分段统计和趋势点放在“数据”。Excel 嵌图应与交付 PNG 逐字节一致。维护系列总表时，每个模式一行，保留目录跳转和其他模块状态；WPS 单元格图片需按图片 ID 核对实际嵌图。

## 插件输入格式

对带 PEAKdetect 采集参数的交替双相波形，插件检查每对采样的正负极值顺序，用多个脉冲拟合周期，并用每个事件的时序残差筛掉不可靠的窗口。组内频率在各脉冲组内计算。窗口频率存入 frequency-windows.csv，逐间距散点仍保存在 frequency.csv。未确认的时间区间留空，需要时以高采样率局部记录复核。报告采用的标称值须能追溯至本次波形特征；使用其他采集作为对照时应记录来源。

标记图直接使用同帧示波器截图，保持原始尺寸。在截图的波形网格内选择走线较少的位置，起始间隔与各输出段的箭头同排，整轮 T 在下方单列。段间停顿保留在走线和分段表中。标注工程使用归档的原生截图作为底图。

采用时长 JSON 以 gap1、t1 等为键，值为秒。幅频 JSON 以输出段为键，可分别提供 amplitude_vpp 和 frequency_hz；每个控制点为 [段内进度, 采用值]，进度从 0 到 1。同一进度允许两个值以表达阶跃。已确认分组输出的组间停顿按原始采样保留。未提供采用值时，插件输出实测统计，使用者按本次信号复核。
